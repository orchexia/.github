# Contributing to ORCHEXIA

Thank you for your interest in contributing to ORCHEXIA.

This repository contains **organization-level GitHub configuration files** (issue templates, pull request templates, workflows, and policies) that apply across ORCHEXIA projects.

---

## 📌 Scope of This Repository

Contributions here typically involve:
- Improving issue or pull request templates
- Updating contribution or governance documents
- Adjusting CI/CD or GitHub workflow configurations
- Improving clarity or consistency of organizational standards

This repository does **not** contain application or system logic.

---

## 🧭 Contribution Guidelines

### 1. Keep Changes Focused
- Make small, well-scoped changes
- Avoid mixing unrelated updates in a single pull request

---

### 2. Follow Existing Structure
- Respect the current folder layout
- Use consistent formatting and naming conventions

---

### 3. Be Clear and Descriptive
- Use clear commit messages
- Explain *why* a change is needed, not just *what* changed

---

## 🔄 Pull Request Process

1. Fork the repository (if applicable)
2. Create a feature branch:
```
git checkout -b update-<description>
```
3. Make your changes
4. Open a pull request with:
- A clear summary
- Relevant context or rationale

All pull requests are reviewed before merging.

---

## 🔐 Security-Sensitive Changes

If your contribution affects:
- Security policies
- Access control
- CI/CD workflows

Please clearly highlight this in the pull request description.

For vulnerabilities or sensitive concerns, follow the instructions in `SECURITY.md`.

---

## 🤝 Code of Conduct

All contributors are expected to:
- Communicate respectfully
- Provide constructive feedback
- Act in good faith

Harassment, abuse, or unprofessional behavior will not be tolerated.

---

---

## 📬 Questions or Suggestions

If you are unsure whether a change belongs in this repository:
- Open a discussion
- Or raise a draft pull request for feedback

---
