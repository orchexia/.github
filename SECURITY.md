# Security Policy

## 📌 Scope

This security policy applies to the **ORCHEXIA GitHub organization configuration repository** (`.github`).

This repository contains:
- GitHub issue and pull request templates
- Contribution and governance documents
- CI/CD workflow configurations (if applicable)

It does **not** contain application code or runtime systems.

---

## 🔐 Reporting a Security Issue

If you discover a security issue related to:
- GitHub workflows
- Repository configuration
- Access control or permissions
- Contribution or governance files

Please report it responsibly.

### Preferred Reporting Method
- Use **GitHub Security Advisories** (private disclosure)

### Alternative
- Contact the repository maintainer directly if advised internally

Please **do not** open public issues for security-related concerns.

---

## ⏳ Response & Handling

Security reports will be:
- Reviewed promptly
- Assessed for impact
- Addressed in a timely manner

Where applicable:
- Fixes will be applied privately
- Public disclosure will occur only after mitigation

---

## 🚫 Out of Scope

The following are **out of scope** for this repository:
- Application-level vulnerabilities
- AI model behavior or outputs
- System-level security issues
- Third-party dependency vulnerabilities (unless directly used in workflows)

Such issues should be reported in the appropriate ORCHEXIA project repository.

---

## 🤝 Responsible Disclosure

We appreciate responsible disclosure and ask that:
- Issues are reported privately
- Adequate time is allowed for mitigation
- Details are not shared publicly before a fix is available

---

## 📄 Policy Updates

This security policy may be updated as the organization evolves.

---

> _“Security starts with responsible communication.”_
