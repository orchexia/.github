# ORCHEXIA

This repository contains **shared GitHub configuration files** for the **ORCHEXIA** organization.

It defines standards and defaults that apply across all ORCHEXIA repositories.

---

## 📌 Purpose of This Repository

The `.github` repository is used to centralize:

- Issue templates
- Pull request templates
- Contribution guidelines
- Security policies
- CI/CD defaults (if applicable)

These configurations help ensure:
- Consistency across repositories
- High-quality contributions
- Clear communication
- Responsible and secure development practices

---

